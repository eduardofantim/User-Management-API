# User Management API - V1

API para gerenciamento de usuários desenvolvida em ASP.NET Core durante meus estudos de back-end.

## 🚀 Tecnologias
* C# / .NET 10
* ASP.NET Core Web API
* Entity Framework Core (SQL Server)
* Bcrypt

## 🛠️ Como rodar a aplicação
1. Clone o repositório.
2. Certifique-se de que a ConnectionString no `appsettings.json` aponta para seu SQL Server local.
3. Execute as migrações do banco de dados (se houver).
4. No terminal, use:
   ```bash
   dotnet run
